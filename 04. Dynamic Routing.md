#### [폴더명] : 폴더명에 대괄호 감싸기
ex) app/breeds/[id]/page.jsx

#### React Router에서의 Dynamic Routing
```TypeScript
export default function Router() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/breeds/:id" element={<Detail />} />
      </Routes>
    </BrowserRouter>
  );
}
```
```TypeScript
// 서버 컴포넌트에서의 params 받기
// app/detail/[id]/page.tsx
const DetailPage = async ({ params }) => {
  const { id } = await params;  // Promise.resolve({ id })
  return <div>Detail 페이지 : {id}</div>
};

export default DetailPage;
```
```TypeScript
// 클라이언트 컴포넌트에서의 params 받기
// app/detail/[id]/page.tsx
"use client"

const DetailPage = () => {
  const { id } = useParams();
  return <div>Detail 페이지 : {params.id}</div>;
};

export default DetailPage;
```

#### 같은 라우트 내 동적 컨텐츠 표현을 위해 searchParams 받기
searchParams는 같은 페이지 내에서 필터링, 정렬, 페이지네이션 등의 상태를 표현하는 데 주로 사용
```TypeScript
'user client'

import { useSearchParams } from 'next/navigation'

export default function SearchBar() {
  const searchParams = useSearchParams()

  const search = searchParams.get('search')

  // URL -> `/dashboard?search=my-project`
  // `search` -> 'myproject'
  return <>Search: {search}</>
}
```
