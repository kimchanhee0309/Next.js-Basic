#### 환경 변수 처리
* 서버 환경(node)에서 환경변수 접근 시에는 자유롭게 환경변수 네이밍 가능
* process.env.DB_HOST
  ```TypeScript
  // .env
  DB_HOST=https://db-host.com
  ```
* 클라이언트 환경(browser)에서 환경변수 접근 시에는 prefix로 **NEXT_PUBLIC_** 을 붙여줌
  ```TypeScript
  NEXT_PUBLIC_MY_HOST=http://localhost:3000
  ```

<details>
  <summary>정적인 metadata 설정</summary>

  ```TypeScript
  export const metadata = {
    title: '...',
    description: '...',
  }

  export default function Page() {}
  ```
</details>

<details>
  <summary>동적인 metadata 설정</summary>

  ```TypeScript
  export async function generateMetadata({ params, searchParams }, parent) {
    // read route params
    const { id } = await params
 
    // fetch data
    const product = await fetch(`https://.../${id}`).then((res) => res.json())
 
    // optionally access and extend (rather than replace) parent metadata
    const previousImages = (await parent).openGraph?.images || []
 
    return {
      title: product.title,
      openGraph: {
        images: ['/some-specific-page-image.jpg', ...previousImages],
      },
    }
  }
 
  export default function BreedsPage({ params, searchParams }) {}
  ```
</details>
