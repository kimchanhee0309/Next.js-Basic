app/ 폴더 내에 route.js 파일을 생성하면, 해당 경로에 API 엔드포인트가 만들어짐
이 파일은 서버에서만 실행되며 GET, POST 등의 HTTP 요청을 처리할 수 있음

#### route handler는 언제 사용하면 좋을까?
1. Client Component에서 api 요청 시 민감한 정보(인증, api key, api url, token 등) 노출 방지(`정보 보안`)
2. Client Component에서 api 요청 시 `CORS 우회`
3. `외부 클라이언트에 REST API 제공`하고 싶을 때

<details>
  <summary>6-1. GET 요청 핸들러 예시</summary>

  ```JavaScript
  export async function GET() {
    const res = await fetch('https://data.mongodb-api.com/...', {
      headers: {
        'Content-Type': 'application/json',
        'API-Key': process.env.DATA_API_KEY,
      },
    })
    const data = await res.json()

    return Response.json({ data })
  }
  ```

  * Dynamic Route 핸들러 예시(params 처리)
    ```TypeScript
    // app/items/[id]/route.js
    export async function GET(
      request,
      { params }
    ) {
      const { id } = await params // 'a', 'b', 'c'
    }
    ```
    
  * searchParams 처리 예시
    ```TypeScript
    export function GET(request) {
      const searchParams = request.nextUrl.searchParams
      const query = searchParams.get('query')
      // query is "hello" for /api/search?query=hello
    ```

  <summary>6-2. POST 요청 핸들러 예시</summary>

  ```TypeScript
  export async function POST(request) {
    // request body 추출
    const body = await request.json()
    await fetch(`${API_URL}/todo`, {
      method: "POST",
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringfy(body)
    })
    return Response.json({ body })
  }
  ```
