#### 구글 폰트 적용
* 구글 폰트를 쓰는 이유:
  * 무료
  * Next.js에서 바로 쓸 수 있게 도와주는 도구 제공(next/fontt/google)
  * css에서 @import로 불러오는 것보다 성능도 좋고, 자동최적화 가능
* 구글폰트 내에서도 `variable font(가변 폰트)`를 선택하는 것이 가장 권장됨

<details>
  <summary>classNAme={inter.className} 적용 방식</summary>

  ```JavaScript
  import { Inter } from 'next/font/google'

  // If loading a variable font, you don't need to specify the font weight
  const inter = Inter({
    subsets: ['latin'],
    display: 'swap',
  })

  export default function RootLayout({ children }) {
    return (
      <html lang="en" className={inter.className}>
        <body>{children}</body>
      </html>
    )
  }
  ```
  * 해당 요소와 모든 하위요소에 폰트가 자동으로 적용
</details>

<details>
  <summary>className={inter.variable} 적용 방식</summary>

  ```JavaScript
  import { Inter } from 'next/font/google'

  // If loading a variable font, you don't need to specify the font weight
  const inter = Inter({
    subsets: ['latin'],
    display: 'swap',
    variable: '--font-inter'
  })

  export default function RootLayout({ children }) {
    return (
      <html lang="en" className={inter.variable}>
        <body className="font-sans">
          {children}
        </body>
      </html>
    )
  }

  // globals.css

  @theme inline {
    --font-sans: var(--font-inter)
  }
  ```
  * 폰트 적용이 되지는 않고, 폰트 적용을 위한 css 변수 설정만 됨
</details>

#### 로컬 폰트 적용
프로젝트 내부에 직접 포함된 폰트 파일 사용할 때 활용
```JavaScript
import localFont from 'next/font/local'

// Font files can be colocated inside of 'app'
const geistSans = localFont({
  src: "./fonts/GeistVF.woff",
  weight: "100 900",
});

export default function RootLayout({ children })
  return (
    <html lang="en" className={geistSans.className}>
      <body>{children}</body>
    </html>
  )
}
```
* 구글 폰트에 없는 폰트 사용할 때 사용
